# Дизайн приложения Eskiz AI

Копия холста «Мебель АИ — UI/UX приложения» (claude.ai/artifact/D3bKN1DKQas1ECFxPUnnkF), версия от 3 ноября 2026.
Каждый `*.dc.html` — один экран 390×844; заголовок экрана и его номер (SCR-xx) — в `canvas.json` → `boards`.
Общие стили (цвета, кнопки, поля, шторки) — блок `/*V3*/ … /*/V3*/` в начале любого экрана.
Анимации — `Motion.dc.html`, общий концепт — `ConceptYa.dc.html`, логотип — `Logo.dc.html`.
