# EMAN Materials: что видно на публичном сайте

Проверено 02.11.2026 по страницам https://eman.uz, которые видит обычный посетитель (без входа, без отправки форм). Это задача этапа 0 из плана: «изучить публичные данные EMAN».

## Главное для продукта

| Факт | Что это значит для нас |
| --- | --- |
| Цены видны без входа, в сумах, HTML с ценами в тексте | Демо-каталог можно наполнить реальными позициями; парсер технически возможен (проверить исходный HTML через curl). Договор и разрешение EMAN — до использования в пилоте |
| Лист ЛДСП 2800×2070 (5,796 м²) — основной формат; есть 4,575 м² у Ultradecor | Формат листа в правилах верный; второй формат нужно добавить, когда узнаем его размеры |
| Цена ЛДСП — за лист (по полю «Площадь 5,796»; явно не написано) | Подтвердить у EMAN |
| Кромкование — услуга с ценой по типу кромки (5 300–10 500 сум, единица не указана, вероятно за метр), кромка отдельно — 1 952–2 440 сум/м | Похоже, услуга кромкования включает кромку. В смете не считать кромку и кромкование дважды — подтвердить у EMAN |
| Распил пакетный: 50 000 сум за лист 5,796; ХДФ (двухпильный) — 18 000 сум | Цены распила в демо-прайсе заменены на эти |
| ЧПУ, фрезеровка, присадка на сайте не найдены | Противоречит допущению PRD (раздел 5 «Производства»), что EMAN делает присадку и фрезеровку. Чертежи деталей с присадкой в MVP нужны; операции формы на ЧПУ — уточнить, кто делает |
| Есть услуга «конструктор» и «дизайнер» | Возможный исполнитель для «нестандарта» (US-7) |
| Онлайн-крой — только после входа; поля и шаблон не видны | Формат CSV по-прежнему неизвестен — уточнить на переговорах или посмотреть с аккаунтом владельца |
| Фасады — 27 моделей с карточками; «профилей купе» как раздела нет (есть «Профили» AGT, Frente) | Система купе у EMAN под вопросом |
| Доставка: 60 000 сум до 300 кг и 4 км, +8 000 сум/км, +5 000 сум за каждые 50 кг сверх 300 кг и за погрузку | Можно считать доставку в оформлении заказа (SCR-14) |
| sitemap.xml и robots.txt — 404, API и выгрузок прайса нет | Парсер — по страницам категорий; ограничений обхода нет, но ходить редко и вежливо |

## Каталог

- Плитные материалы: ЛДСП (354 позиции, 18 страниц по 20), акриловые панели, ЛМДФ, ОСБ, МДФ, ЛХДФ, ХДФ, HPL.
- Фурнитура: Italiana Ferramenta, Hettich, Kesseböhmer, System, Citterio, Salice, Cebi, Starax, Mesan, Samet, Klus.
- Столешницы и стеновые панели: Союз, Кедр, Egger, Ultradecor, Термопласт, Декоплинт, Slotex. Толщины 26, 27, 38, 40, 56 мм.
- Ещё: фасады, мойки, кромка (ПВХ/ABS, 0,4–3 мм, ширина 19–42 мм), стекло и зеркала, клей, профили, услуги.
- Бренды плит: Egger, Ultradecor, SwissKrono, Kastamonu, Kronostar и др. Kronospan не встречается.

Адреса страниц: категория `/ru/product/{id}/list/?page=N`, бренд `?brand=…`, карточка `/ru/product/{id}/`.

## Что спросить у EMAN

1. Цена ЛДСП — за лист? Размер формата 4,575 м²?
2. Кромкование включает кромку? Цена за метр?
3. Делаете ли присадку и фрезеровку на ЧПУ? Принимаете ли DXF?
4. Формат онлайн-кроя: поля, шаблон, как передаётся кромка по сторонам и направление текстуры.
5. Есть ли система профилей купе и её вычеты.
6. Можно ли брать цены с сайта или вы дадите выгрузку или API.

## Каталог декоров и текстуры (04.11.2026)

- Сбор: `api/scripts/scrape_eman_decors.py` (публичные списки и карточки, ~1 запрос в 1,2 с, кэш страниц) → `api/scripts/build_eman_decors.py` (нормализация, картинки → JPEG-плитки). Результат: `core/src/mebel_core/data/eman_decors.json`, текстуры — `api/static/textures/` (в git не входят, раздаются как `/static/textures/…`).
- Не вошло: у позиций «Угол», «Плинтус», «Мебельные щиты» нет декора как материала — пропущены; у кромки (`edge`) нет текстур, только цена и размер.
- **Изображения декоров принадлежат EMAN. Только для пилота: до продакшена нужно письменное разрешение EMAN на использование картинок и цен (или выгрузка от них).** Когда EMAN даст выгрузку, `build_eman_decors.py` заменить на импорт из неё.
- Лист не 2800×2070 (акрил 2800×1220, Ультрадекор 2500×1830 и т. д.) в смете пересчитан по цене за м² на стандартный лист — раскрой в ядре считает листы 2800×2070.
