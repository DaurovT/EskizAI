# Мебельный конструктор

Приложение для малых мебельных цехов: фото или описание клиента → модель из деталей → смета по прайсу поставщика → 3D и AR для клиента → файлы для станка и заказ материалов.

- Требования: [PRD_mebel.md](PRD_mebel.md)
- План и состояние: [PLAN_razrabotki.md](PLAN_razrabotki.md)

## Как устроено

```
фото / текст ──► ai/ (Claude) ──► дерево модулей (JSON) ──► core/ ──► модель деталей
                                                                      │
          ┌───────────────┬───────────────┬──────────────┬────────────┤
          ▼               ▼               ▼              ▼            ▼
   3D (viewer/)     AR (GLB)        смета, раскрой   CSV, DXF,    проверки и
   в app/ и web/                    «от–до»          Excel, PDF   исправления
```

Модель деталей строится только на сервере (`core/`). ИИ отвечает только за понимание: что на фото и что хочет клиент; детали, цены и файлы считает код.

| Папка | Что это | Стек | Запуск |
| --- | --- | --- | --- |
| [core/](core/) | Ядро: модули, правила, модель деталей, раскрой, смета, файлы | Python | `cd core && uv sync && uv run pytest` |
| [ai/](ai/) | Фото/текст → дерево модулей, вопросы, правки словами | Python, Claude API | `cd ai && uv sync && uv run pytest` |
| [api/](api/) | Сервер: вход, проекты, версии модели, смета, ссылки клиента, ИИ, файлы, каталог, админ-эндпоинты | FastAPI, PostgreSQL | `cd api && uv sync && uv run pytest` |
| [viewer/](viewer/) | Общая 3D-сцена: детали, открывание, «взрыв», GLB | TypeScript, three.js | `cd viewer && npm install && npm test` |
| [web/](web/) | Ссылка клиента с 3D, AR и сметой; админка | Next.js | `cd web && npm install && npm run dev` → `/p/demo` |
| [app/](app/) | Приложение мастера | React Native, Expo | см. `app/README.md` |
| [schemas/](schemas/) | Схема дерева модулей и примеры выходов ядра | JSON | `cd core && uv run python scripts/dump_schema.py` |

## Что нужно, чтобы запустить по-настоящему

- `ANTHROPIC_API_KEY` — для ИИ (без ключа работает всё, кроме распознавания и правок словами).
- PostgreSQL и Redis — `cd api && docker compose up -d`.
- Реальный прайс EMAN вместо демо-прайса в `core/src/mebel_core/pricing.py` (демо-цены выдуманы).
- Провайдер SMS или Telegram Gateway для кода входа (в разработке код `0000`).
